# 🌾 Agri Products Showcase Website (React + Redux Toolkit)

A simple and clean React-based web application to display **agriculture-related products** such as vegetables with **names and prices**.  
The project includes a **Home page**, **Cart**, and **Checkout** pages.  
State management is handled using **Redux Toolkit**.

---

## 🚀 Features

### ✔ Product Listing  
- Displays vegetables with image, name, and price  
- Clean UI using CSS components  

### ✔ Add to Cart  
- Users can add/remove items  
- Cart updates dynamically using Redux Toolkit  

### ✔ Checkout Page  
- Shows final items    
- Simple and user-friendly layout  

### ✔ State Management with Redux Toolkit  
- Centralized store  
- Slices for cart and products  
- Smooth performance  

---

## 🛠️ Technologies Used

| Technology | Purpose |
|-----------|---------|
| **React JS** | Frontend framework |
| **Redux Toolkit** | State management |
| **CSS** | Styling & layout |
